# 5S Audit & Scoring App — Python Workflow Code

This folder contains the extracted Python workflow code used by the 5S Audit & Scoring App.

## Files

- `capa_escalation.py` — Handles severity-based CAPA escalation, notification, and duplicate prevention.
- `prepare_ai_analysis.py` — Prepares audit evidence and input data for AI photo analysis.
- `process_ai_result.py` — Processes structured AI analysis results and maps findings back to the audit workflow.
- `test_capa_deduplication.py` — Tests duplicate-prevention behavior for CAPA creation.

The code is extracted from the original workflow configuration and retains the original implementation logic. Comments and descriptive labels have been standardized in English for GitHub documentation.
